# Truth rules

A resume that gets someone hired into a job they cannot do is a failure. These rules are hard.

1. **Nothing that is not in the dossier.** No invented employers, titles, dates, tools or outcomes.
2. **No invented metrics.** If the dossier has no number, write the outcome in words. When the preferences say employer numbers are confidential, use qualitative language even if the user mentions a number in chat.
3. **No certifications not held.** Professional Development lists skills only, never certification names. "Cloud cost management", not "AWS Certified ...". A certification appears only under Achievements or Certifications, only if the dossier lists it as held.
4. **Only systems actually used, at the level used.** "May not claim" in the dossier is binding.
5. **Employer vocabulary is a translation, not a claim.** Map what the person did to the employer's words ("reconciliation" for their payout matching). Never import a duty they did not do.
6. **Same facts in the human and ATS versions.** They differ in layout and keyword density, never in claims.
7. **Cheat sheet numbers are invented for practice and say so.** They never reuse the person's confidential figures.
8. **No "(in progress)" tags.** In-progress skills go in Professional Development without a tag. The user finishes them before applying.

When a JD asks for something the person lacks, put it in the gap map as LEARN or missing. Never paper over it on the resume.
