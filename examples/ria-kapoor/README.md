# Worked example: Ria Kapoor (fictional)

Ria, her employer Tiffinly, the target company Ledgerline, and every number below are invented.
This folder has the same layout the skill creates in a real user's workspace, so it doubles as a
reference for what each file holds.

| File | What it is |
|---|---|
| `profile/dossier.md` | Every verified fact about Ria. All documents are derived from it. |
| `profile/changelog.md` | Dated record of every dossier change. |
| `jobs/ledger.md` | One row per application. |
| `jobs/ledgerline-senior-backend-payments/jd.md` | The job description's keyword map. |
| `jobs/ledgerline-senior-backend-payments/gapmap.md` | KNOW, LEARN and missing, decided with Ria. |
| `jobs/ledgerline-senior-backend-payments/cheatsheet.tex` | The per-job interview sheet, 2 pages. |
| `jobs/ledgerline-senior-backend-payments/human.tex` | Human resume, one-column classic layout, 1 page. |
| `jobs/ledgerline-senior-backend-payments/ats.tex` | ATS resume, 1 page. |
| `topics/cheatsheet_ledgers.tex` | Topic sheet for her biggest gap, reusable for any payments job. |
